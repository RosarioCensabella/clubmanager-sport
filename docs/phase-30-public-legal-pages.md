# ClubManager Sport — Fase 30: Pagine web pubbliche legali

## Obiettivo

Preparare pagine HTML pubbliche per privacy policy, termini d’uso e richiesta eliminazione account.

Queste pagine sono necessarie per la preparazione alla pubblicazione sugli store, in particolare per fornire un link web pubblico relativo alla richiesta di eliminazione account e dati associati.
