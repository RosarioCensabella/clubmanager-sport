# ClubManager Sport

App mobile cross-platform per società sportive dilettantistiche.

L'obiettivo è creare una versione 1.0 completa, stabile, sicura e pubblicabile su App Store e Google Play Store.

## Stato del progetto

Il progetto è in sviluppo attivo.

Fasi completate:

- Fase 1: Analisi PRD
- Fase 2: Scelta stack tecnologico
- Fase 3: Architettura generale
- Fase 4: Setup progetto Flutter
- Fase 5: Setup repository

## Stack tecnico

- Flutter
- Dart
- Supabase
- PostgreSQL
- Supabase Auth
- Supabase Storage
- Supabase Row Level Security
- Supabase Edge Functions
- Firebase Cloud Messaging
- Sentry
